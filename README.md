This my website that I am building with Next.js and Tailwind CSS. I am using this project to learn Next.js and Tailwind CSS. I am also using this project to learn how to use the GitHub API to fetch data from GitHub.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
